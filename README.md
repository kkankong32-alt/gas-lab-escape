# 풀어서 잠금 해제 — 기체 연구소 탈출

초등학교 4학년 과학 「여러 가지 기체」를 바탕으로 만든 1인칭 웹 방탈출 게임입니다.

## 가장 간단한 실행

**`게임_시작.html`을 Chrome 또는 Edge에서 여세요.** 또는 `게임_실행.cmd`를 두 번 클릭하세요.

HTML 안에 게임 코드, 3D 모델, 재질, 환경광, 한국어 글꼴이 모두 들어 있습니다. 설치, 계정, 인터넷 연결, 서버가 필요 없습니다. 파일을 옮길 때도 이 HTML 하나로 플레이할 수 있습니다. PC 오프라인 실행용입니다. 태블릿·스마트폰은 아래 웹 배포본을 사용하세요.

진행 기록은 사용한 브라우저의 로컬 저장소에 자동 저장됩니다. 파일 위치나 브라우저를 바꾸면 기존 기록이 이어지지 않을 수 있습니다. 시크릿 모드나 저장 차단 환경에서는 기록이 유지되지 않을 수 있습니다.

## 조작

| 조작 | 동작 |
|---|---|
| ↑ ↓ ← → 또는 WASD / 마우스 | 이동 / 시점 |
| E 또는 클릭 | 가까운 실험대 확대 |
| 병 클릭 → 받침 클릭 | 병 집기 / 놓기 |
| 병 드래그 → 받침 | 직접 옮기기 |
| 펌프를 한 번 잡고 위아래 왕복 | 하강을 완료할 때마다 공기 주입 / 배기 |
| 피스톤 위아래 드래그 | 밀폐 공기 부피 조절 |
| 밸브 클릭·탭 또는 좌우 드래그 | 공기 공급 / 공급량 조절 |
| 두 연결구 차례로 클릭 | 배관 연결 / 같은 연결 분리 |
| Esc | 확대 조작 종료 / 일시정지 |
| G | 다음 목적지까지 자동 이동 / 중단 |
| H / J / V / M | 현재 단계 힌트 / 탐구 기록 / 기체 투시 / 도구 메뉴 |

기체 투시는 실제 입자를 관측하는 기능이 아닌 설명용 모식도입니다. 실험 초기화는 해당 실험 장치를 되돌리며 이미 얻은 안전 회로와 탐구 기록은 보존합니다.

## 초등학생용 UI·UX 개선

- 새 탐구는 제1실험실 입구를 바라보며 시작합니다. 바닥 유도선과 번호 표지를 따라가면 됩니다.
- 상단에는 현재 해야 할 행동 하나가 표시됩니다. 첫 실험은 집기 → 저울 → 주입 받침 → 펌프 → 재측정을 상태에 맞춰 안내합니다.
- 나머지 실험은 관찰 목표를 먼저 보여 줍니다. H 힌트를 사용하면 현재 단계의 구체적인 조작과 목표 기구 강조가 나타납니다.
- 물체에 마우스를 올리면 클릭·집기·드래그 방향을 표시합니다. 일반 글자 16px 이상, 목표 22px, 측정값 26px를 사용합니다.
- 중앙 장치는 네 실험을 마치기 전까지 잠겨 있습니다. 부분 진행 상태도 저장되며 이어하기 시 다음 행동을 다시 계산합니다.
- 시작하면 마우스가 게임에 잠깁니다. E로 실험을 열면 포인터가 풀리고, Esc로 탐색에 복귀합니다. 탐색 중 H/J/V는 마우스를 풀지 않고 사용할 수 있습니다.

## 안내 일관성 보완 (2026-10-21)

- 상단 목표와 물체 안내를 같은 단계 판단으로 생성합니다. 연결된 받침은 연결 상태만 알리고, 완료한 주입·가열·측정·기체 연결을 다시 요구하지 않습니다.
- 힌트는 전체 순서를 다시 나열하지 않고 **현재 단계의 정확한 조작**을 알려 줍니다. 첫 실험은 대상 강조를 기본 제공하고, 이후 실험은 힌트를 요청하면 대상 강조를 켭니다.
- 실험 중 3D 렌더링 영역을 상·하단 UI 영역과 분리했습니다. 제목·계기판·기구를 안내판 뒤에 그리지 않으며, 카메라 구도를 실험별로 맞췄습니다.
- 하단은 **힌트 / 도구 / 나가기** 세 버튼입니다. 투시·기록·조작 방법·현재 실험 다시 하기는 도구 메뉴에 있습니다. J/V 단축키도 유지됩니다.
- 실험 성공 후 나가면 복도를 바라보고 다음 실험실 목표가 표시됩니다.

## 구현된 실험

1. 같은 500mL 병을 재고, 주입 장치로 옮겨 공기를 넣은 뒤 다시 무게 비교.
2. 고무막을 씌운 집기병 가열, 겉면 닦기, 냉각. 탄성 고무막과 걸쇠 움직임.
3. 주사기 마개를 닫고 피스톤으로 압축. 진공 용기 바깥 공기를 제거하여 풍선 팽창.
4. 헬륨의 부력, 이산화 탄소의 소화, 질소의 산소 치환, 산소의 연소 도움.
5. 최종 배관 2개 연결, 밸브 개방, 가열, 압력과 피스톤의 연쇄 작동, 출입문 개방.

산소는 연료처럼 타지 않습니다. 불꽃은 장치 안의 연료가 타는 표현입니다. 질소는 식품을 즉시 신선하게 되돌리지 않습니다. 실제 위험 실험을 따라 하도록 안내하지 않습니다.

## 개발 / 재빌드

Node.js 22 이상을 권장합니다.

```text
npm install
npm run dev
npm test
npm run build
npm run package:offline
```

`dist/`는 웹서버에 그대로 올릴 수 있는 배포 폴더입니다. 소스는 `src/`, 모델은 `public/assets/`, 정밀 기구를 재생성하는 Blender 스크립트는 `tools/build-instruments.py`에 있습니다.

```text
blender --background --factory-startup --python tools/build-instruments.py
```

실험 계산은 `src/science.ts`, 장면·모델 표현은 `src/world.ts`, 입력·화면은 `src/main.ts`, 상태별 안내는 `src/guidance.ts`, 저장은 `src/storage.ts`로 분리했습니다.

## 알려진 범위와 한계

- 네 실험과 탈출까지 동작하는 실행본입니다. 초등학생 대상의 사용성 검사는 아직 하지 않았습니다.
- 20~35분 플레이 시간, 실제 학교 저사양 PC에서 30FPS 이상은 별도 현장 검증이 필요합니다.
- 정밀 기구는 실측 CAD가 아니라 교과서 사진과 실험 구조를 참고한 독립적인 Blender 모델입니다. 확대 조작을 위해 화면에서 크기를 조정했습니다.
- 기체 계산은 교육용 근사 모델이며, 실제 고무의 비선형 재료 시험이나 유체·연소 시뮬레이션을 대체하지 않습니다.
- 실험 장비는 배경 다음에 불러옵니다. 모든 방에 진입할 때 별도로 스트리밍하는 방식은 아닙니다.
- 모바일 터치는 Chromium 에뮬레이션에서 검수했습니다. 실제 iPhone·iPad·Android 하드웨어와 Safari는 미검증입니다. VR·멀티플레이는 지원하지 않습니다.
- 원본 교과서와 실험관찰 PDF는 수정하지 않았으며, PDF 페이지 이미지는 게임에 포함하지 않았습니다.

## PC·태블릿·스마트폰 개선 (2026-10-21)

- 성공 후 **다음 실험실로 이동**을 누르면 실제 복도를 따라 이동합니다. 네 실험을 마치면 중앙 장치로 안내합니다. 도착 후 **실험 시작**을 누르세요.
- 직접 이동, 이동 중단, 이동 연출 건너뛰기를 제공합니다. 건너뛰기도 검증된 경로를 빠르게 이동하며 벽을 넘지 않습니다. PC에서는 G로 언제든 안내를 시작하거나 멈춥니다.
- 터치는 왼쪽 스틱으로 이동하고 오른쪽 빈 화면을 끌어 둘러봅니다. 두 손가락을 동시에 사용할 수 있습니다. 실험 중에는 스틱이 사라집니다.
- 병·카트리지 선택 → 받침·연결구 선택으로 옮깁니다. 펌프·진공 펌프는 손을 떼지 않고 왕복합니다. 정상 하강만 한 번 계산하며 상승·떨림은 주입하지 않습니다.
- 좁은 화면은 **측정값**을 눌러 수치를 펼치고, **기구 확대 / 전체 보기**를 전환합니다. 세로 화면도 진행할 수 있습니다. 가로 안내는 닫을 수 있습니다.
- 세로 실험 보기는 카메라를 가리는 연구소 벽을 숨기고 실험대에 집중합니다. 전체 보기에서는 기구 모두를 보여 주고, 확대 보기에서는 선택한 기구를 크게 보여 줍니다.
- 모바일은 픽셀 비율 1·그림자 끄기를 기본 적용하고, 실험 중 다른 실험대는 렌더링하지 않습니다. 설정에서 품질을 바꿀 수 있습니다.

## 공통 웹 배포 / PWA

`dist/` 안의 파일 전체를 HTTPS 정적 호스팅에 올리세요. 루트 또는 하위 경로 배포를 지원합니다. 폴더 구조를 유지하고 HTML·JS·CSS·GLB·GLTF·BIN·HDR·PNG·JPG·웹 매니페스트·서비스 워커 파일을 모두 배포해야 합니다.

첫 접속은 인터넷이 필요합니다. 서비스 워커가 게임과 에셋 전체를 캐시한 이후 같은 주소에서 오프라인 재접속할 수 있습니다. 브라우저 저장 공간 부족·자동 정리·시크릿 모드·사용자의 사이트 데이터 삭제로 캐시와 저장 기록이 사라질 수 있습니다. 홈 화면 추가 방식과 오프라인 보존 기간은 브라우저마다 다릅니다. 파일 URL에서는 서비스 워커를 등록하지 않습니다.

업데이트 시 `dist/` 전체를 함께 교체하세요. 서비스 워커는 파일 내용으로 캐시 버전을 구분하고, 사용 중인 구 버전을 갑자기 교체하지 않습니다. 게임 탭을 모두 닫은 후 다시 열면 새 버전이 적용됩니다. 동일 출처·경로에서는 기존 저장 형식을 그대로 읽습니다. PC 파일 URL의 저장 기록과 HTTPS 사이트의 기록은 서로 다른 저장소입니다.

검수: `qa/DEVICE_REPORT.md`. 테스트 실행 중 개발 서버가 필요합니다. `node tools/playthrough.mjs`, `node tools/qa-devices.mjs phone`, `node tools/qa-devices.mjs tablet`, `node tools/qa-devices.mjs landscape`, `node tools/qa-device-input.mjs`, `node tools/qa-device-layout.mjs`를 사용합니다. 웹 오프라인 검사는 `npm run preview -- --port 4173` 실행 후 `node tools/qa-pwa.mjs`로 합니다.

중앙 탈출 장치는 **저장통 출구 → 가열 입구**, **가열 출구 → 피스톤 입구**의 두 연결을 차례로 완성합니다. 이후 공급 밸브를 열고 가열을 켜면 압력이 높아지고 피스톤이 잠금을 밉니다. 오른쪽(휴대전화에서는 아래) 패널에서 각 기구의 역할과 지금 사용할 연결구를 확인할 수 있습니다. 화면 버튼 또는 3D 기구를 직접 조작할 수 있으며, 아직 할 수 없는 조작은 이유를 안내합니다.

온도 실험에서 병을 수조에 놓으면 자동으로 고무막을 확대합니다. 가열 관찰을 마치면 실험대로 돌아와 겉면을 닦고 냉각합니다. 관찰 버튼으로 다시 확대할 수도 있습니다. 곧은 점선은 처음 높이, 둥근 금색 윤곽은 따뜻했던 모습입니다.

기체 이름과 쓰임은 선명한 화면 하단 카드로 선택·연결합니다. 첫 실험 개념 정리는 두 병 상태를 저울에서 비교한 뒤 실제 무게 차이를 확인합니다. 전후 비교 이미지와 검수 근거는 qa/REBOOT_REPORT.md에 정리합니다.
